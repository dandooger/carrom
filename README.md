# קארום

משחק קארום לטלפון. פותחים ב-https://dandooger.github.io/carrom/ ולוחצים "התקן אפליקציה".

- `game.html` — כל המשחק (גם הגרסה שב-Claude).
- `python build.py` — בונה את `index.html` ו-`sw.js` לאתר.
- `python make_icons.py` — מצייר את האייקונים.

אונליין וחשבונות עוברים דרך שרת הודעות חינמי (MQTT), כמו בצ'יטה.

- `old/` — הגרסה הקודמת (העפה באצבע, בלי חץ), קבועה: https://dandooger.github.io/carrom/old/
